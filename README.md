### About me

I'm a software engineer who likes building things properly: from the service a user talks to, down to the infrastructure it runs on. I enjoy taking a system apart to see how it behaves under real conditions, then making it faster, more predictable and easier to trust.

### What I'm into

- **Backend and distributed systems:** APIs, microservices and how services talk to each other
- **Performance:** concurrency, latency, and finding where the time actually goes
- **Systems and infrastructure:** Linux, containers, and controlling the environment code runs in
- **Measuring things properly:** benchmarks and experiments that someone else can rerun and get the same answer
- **Outside code:** learning Japanese
