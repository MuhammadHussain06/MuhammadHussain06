### About me

I'm a software engineer who likes building things properly: from the service a user talks to,<br/>
down to the infrastructure it runs on. I enjoy taking a system apart to see how it behaves<br/>
under real conditions, then making it faster, more predictable and easier to trust.

### What I'm into

**Backend and distributed systems:** APIs, microservices and how services talk to each other<br/>
**Performance:** concurrency, latency, and finding where the time actually goes<br/>
**Systems and infrastructure:** Linux, containers, and controlling the environment code runs in<br/>
**Measuring things properly:** experiments that someone else can rerun and get the same answer<br/>
